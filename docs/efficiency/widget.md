# 桌面小组件

> 点一下就能记

我们提供了 4 个桌面小组件，覆盖记录、搜索等主要使用场景，添加后在手机桌面即可快速启动相应功能。

## iOS 添加小组件

1. 长按桌面空白处进入编辑状态
2. 点击 + 号进入小组件库
3. 在搜索框中输入「Get笔记」
4. 左右滑动选择喜欢的小组件
5. 点击「添加」

## 华为手机添加小组件

1. 长按桌面空白处进入编辑状态
2. 点击屏幕左下角的「服务卡片」
3. 页面下滑至底部，点击「窗口小工具」
4. 下滑找到 Get笔记，长按任一小组件
5. 点击「添加至桌面」，或者直接拖拽到桌面

## 可用小组件

| 小组件 | 功能 |
|-------|------|
| 语音速记 | 一键开始语音录音 |
| AI 搜索 | 快速进入搜索页面 |
| 新建笔记 | 快速新建文本笔记 |
| 笔记列表 | 查看最近笔记 |
