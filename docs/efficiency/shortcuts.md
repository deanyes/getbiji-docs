# 快捷指令

> 效率翻倍（iOS专属）

## 一、实体操作按钮

如果你的手机是 **iPhone 15 Pro** 或 **iPhone 16 全系列**，可以将手机的实体操作按钮设置为 Get笔记快捷指令。

设置完成后，长按手机左侧边的操作按钮（原静音按钮）即可快速打开 Get笔记。

### 设置步骤

1. 打开系统「设置」，向上滑动找到「操作按钮」后点击进入
2. 向左滑动找到「快捷指令」后，点击按钮「选取快捷指令」
3. 在顶部搜索框输入 "Get笔记"，选择已添加的 Siri 快捷指令
4. 也可以点击「打开 App…」，直接选择 Get笔记

## 二、轻点背面

轻点两下或三下 iPhone 背面即可快速执行操作。

### 设置步骤

1. 在手机「设置」里，打开「辅助功能」，选择「触控」
2. 在「触控」页面下滑至最底部，点击「轻点背面」
3. 根据个人需求设置「轻点两下」或「轻点三下」
4. 关联设置为 Get笔记相关的快捷指令

## 推荐配置

| 触发方式 | 推荐指令 | 场景 |
|---------|---------|------|
| 操作按钮 | 语音速记 | 随时快速录音 |
| 轻点两下 | AI 搜索 | 快速查找笔记 |
| 轻点三下 | 会议录音 | 开会时快速启动 |

::: tip 小技巧
把最常用的功能设置为操作按钮，次常用的设置为轻点背面，这样可以覆盖大部分使用场景。
:::
