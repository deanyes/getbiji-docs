# Siri 唤起

> 叫一声就能用（iOS专属）

通过 Siri 语音指令快速启动 Get笔记功能，解放双手。

## 添加方法

1. iOS 用户打开 Get笔记 App
2. 点击右上角头像，进入个人中心
3. 找到【Siri、操作按钮等快捷指令】入口
4. 点击 "+" 按钮，添加需要的快捷指令

## 支持的快捷指令

| 指令 | 口令示例 | 功能 |
|-----|---------|------|
| 🎙️ 语音笔记 | "开始录" | 快速启动语音笔记功能 |
| 👥 会议录音 | "去开会" | 快速启动线下会议录音 |
| 🤖 AI 助手 | "问助手" | 向 AI 助手提问 |
| ⌨️ 文本笔记 | "写笔记" | 一键进入笔记编辑界面 |
| 🔍 笔记搜索 | "搜笔记" | 快速进入搜索页面 |

## 使用场景

- 🚗 开车途中突然有灵感，用语音笔记快速记录
- 🏃 运动时记录训练数据，避免手机操作
- 🧑‍🍳 烹饪时双手被占用，用语音查找食谱笔记
- 📝 会议中需要快速记录，一键启动文本笔记

::: tip 使用建议
- 可以根据个人习惯自定义触发语句，让操作更自然
- 建议在安静环境下使用语音指令，提高识别准确率
:::
