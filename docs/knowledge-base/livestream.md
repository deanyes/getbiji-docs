# 帮你听直播

> 🎧 Get 笔记帮你听直播，知识不再错过。

只需将直播链接或二维码上传，AI 就能替你全程聆听并记录，生成清晰的内容总结和章节纪要。

## 如何使用

1. 创建一个个人知识库，在知识库内，点击"添加内容"按钮
2. 选择"订阅直播/博主"
3. 支持订阅 **得到App直播** 和 **视频号直播**
4. 直接粘贴直播链接即可订阅
5. 直播结束后，Get 笔记会帮你生成清晰的内容总结和章节纪要（AI 需要 30-40 分钟的分析处理）

::: warning 注意
- 已下架的直播，不支持订阅
- 会员专享的直播，不支持订阅
:::
