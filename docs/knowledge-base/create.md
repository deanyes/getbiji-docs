# 创建知识库

## APP端使用

1. 从 APP 首页顶部"更多"入口进入
2. 点击知识库页面右上角"+新建"按钮
3. 创建后，即可在知识库中上传文件、订阅直播、订阅博主或添加已有笔记

::: tip 容量说明
- **普通用户**：可免费创建 10个知识库，空间共30G
- **PRO会员**：可创建知识库数量不限，空间共500G
:::

## 网页端使用

1. 打开网页端访问地址：biji.com
2. 已开通内测的用户，可以看到左侧菜单上的"知识库"入口
3. 点击创建知识库

::: warning 注意
如果删除知识库，则知识库及其中的文件内容也会一并删除，请谨慎操作。
:::
