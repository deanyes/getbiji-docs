# 智能拍书

> 拍照即用，3秒数字化，纸质书笔记永不丢失！

高质量 OCR 提取书页上的文字，智能识别书籍信息，AI 自动整理成结构化笔记，并分类到对应书籍下。让纸质书阅读痕迹变成可搜索、可应用的数字资产。

## 适用场景

- **纸质书阅读**：将书中划线、批注快速数字化保存
- **图书摘录**：重要段落、金句、观点一拍即存
- **学术研究**：论文、专业书籍内容提取和整理
- **学习复习**：快速回顾多本书的核心要点
- **写作素材**：AI助手帮你在海量读书笔记中找到书中观点

::: warning 不适用的场景
- 非文字内容（如乐谱、地图、纯图片等）
- 字迹模糊或页面破损严重的书页
:::

## 如何使用

1. 打开 APP，点击首页底部 + 更多入口
2. 点击「智能拍书」，对准书页内容进行拍摄
3. 系统会自动矫正角度、去除阴影、优化清晰度
4. 默认是自动识别书籍，右边同时会展示最近识别过的书籍（如有），可以手动切换
5. 点下一步，AI 开始智能处理：提取文字内容 → 识别并确认书籍信息 → 生成结构化笔记
6. 确认书籍信息，如识别有误可手动搜索或添加
7. 笔记自动归类到对应书籍下，支持继续拍照或查看整理结果

## 拍照限制

- 单次最多支持识别 **5 张图片**
- 确保文字清晰可见
- 避免手指遮挡重要文字区域
- 光线充足的环境下拍摄效果更佳

## 查看书籍笔记

所有书籍笔记，可以通过首页左上角的菜单进入查看，会以书籍视图形式呈现。

::: tip 小技巧
支持跳转到对应书籍的章节段落查看原文。
:::
