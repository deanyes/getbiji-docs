# 语音口令

> 录音中说句话，AI 帮你标记重点

录音时说出口令词，AI 自动捕捉关键内容并特别处理——标记重点、提炼金句、总结要点，动动嘴就能完成。

## 适用场景

- **课堂听讲**：老师讲到重点时，说一句「帮我记一下」，AI 自动捕捉该知识点并总结，2小时的课10分钟就能复习完
- **读书思考**：看到精彩段落念出来，说一句「这段不错」，手不离书、眼不离页面，看完后读书笔记自动整理好
- **灵感捕捉**：开车、通勤时突然冒出好想法，说一句「这个想法记一下」，到了目的地灵感全都在
- **听播客/音频节目**：一边听一边录，听到有启发的观点说一句「这个有启发」，一期听完金句自动整理好
- **语音日记/个人复盘**：每天录一段语音回顾，哪些特别想记住的说一句「这个很重要」，AI 会把标记的内容作为重点
- **带娃记录**：孩子突然说了句可爱的话，你正在忙没法掏手机，说一句「这句真可爱」就能记下来

## 核心功能

- **自定义口令词**：支持设置最多 3 个口令词，每个可指定不同的处理要求
- **实时识别**：录音过程中 AI 实时监听口令词，无需手动操作
- **智能处理**：识别到口令词后，AI 自动按你设定的要求进行处理
- **标记整合**：处理结果统一展示在笔记的「标记」tab 中，同时在智能总结中重点标注

## 如何使用

1. 打开 App，进入「我的账号」页面，点击「语音口令」
2. 开启「开启语音口令功能」开关
3. 点击「添加口令词」，输入口令词（如「帮我记一下」）
4. 填写对应的处理要求（如「捕捉当下讲到的知识点并总结」）
5. 最多可添加 3 个口令词，设置完成后即可生效
6. 正常使用录音功能，需要标记时直接说出口令词即可
7. 录音结束后，在「标记」tab 中查看所有口令词触发的处理结果
